Tree-sitter is an incremental parser generator used in modern editors like Neovim, Helix, and VS Code for syntax highlighting, error highlighting, and code navigation. These grammars enable complete language support for all RDF serializations and SPARQL in these editors for the first time.

As an open-source contribution, other developers can use these grammars to improve their own RDF tools. Since Tree-sitter provides bindings for many programming languages (Rust, Python, JavaScript, Go, C, Ruby, Swift, WebAssembly), integration into custom tools is straightforward. This strengthens the ecosystem for semantic web technologies and benefits the PMD community and other Linked Data projects.

## Supported Formats

**RDF 1.1:**

- Turtle
- TriG
- N-Triples
- N-Quads
- SPARQL

**RDF 1.2:**

- Turtle
- TriG
- N-Triples
- N-Quads

## Benefits

- **Syntax highlighting** for RDF files in editors (Neovim, VSCode, etc.)
- **Incremental parsing** for fast real-time analysis
- **Multi-language bindings** (Rust, JavaScript, Python, Go, etc.)
- **Highlight queries** included for semantic token support
